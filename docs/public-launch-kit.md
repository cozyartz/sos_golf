## DEV.to / Hashnode native version

### Golf That Travels Beyond One Course

Golf has always been more than a number on a card. State of Stick Golf explores what happens when a round can carry its course context, trusted records, physical moments, and memory beyond one course—without collapsing every kind of evidence into a single “verified” label.

The project is built around five distinct records:

- official strokes;
- format points;
- physical proof;
- passport history;
- advisory intelligence.

That separation is the important technical decision. A tap can establish interaction with a physical touchpoint. It cannot silently prove strokes, handicap, yardage, course conditions, or an official result. A deterministic rules engine can explain a competition record. It cannot invent one.

The public repository includes the Golf experience, course and network models, Worker/D1/DO foundations, offline-round concepts, operator surfaces, and tests for competition, provenance, authorization, services, and bounded intelligence.

It also includes a deliberately honest boundary: demonstration data does not imply a live partner, production adoption, revenue, payment flow, or independently validated golf data.
